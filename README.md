# QR-Ku — QR Code Generator & Toolkit

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6?logo=typescript)](https://typescriptlang.org)

Pembuat QR code serbaguna untuk berbagai kebutuhan: WiFi, WhatsApp, vCard kontak, menu restoran, dan QR umum. Gratis, privat, berjalan di browser.

**Live:** https://qr-ku.pages.dev

---

## Fitur

- 📶 **QR WiFi** — Bagikan password WiFi tanpa mengetiknya
- 💬 **QR WhatsApp** — Link langsung ke chat WA tanpa simpan nomor
- 👤 **QR vCard** — Kartu nama digital
- 🍽️ **QR Menu Restoran** — Buat QR menu dengan satu klik
- 📋 **Riwayat** — Simpan QR yang pernah dibuat
- 📲 **PWA** — Bisa dipasang di HP

---

## Quick Start

```bash
git clone https://github.com/alfindigital/qr-ku.git
cd qr-ku
npm install
npm run dev
npm run build
```

---

## Stack

- TanStack Start + TypeScript 5
- Tailwind CSS + shadcn/ui
- PWA ready
